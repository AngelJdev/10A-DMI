Recorrido de una pregunta

MessageFieldBox envía el texto a ChatProvider. Si termina en ?, se consulta yesno.wtf, se transforma la respuesta en Message y ChatScreen actualiza la conversación.

Dependencias

presentation → config / infrastructure → domain. Message permanece independiente de Flutter y del cliente HTTP.

1 · EntradaEl usuario escribe y envía una pregunta terminada en ?.
2 · EstadoChatProvider agrega el mensaje de carga y ordena las consultas.
3 · APIGetYesNoAnswer sortea la opción y llama una vez a yesno.wtf.
4 · RespuestaYesNoModel crea el mensaje localizado con GIF y hora.
