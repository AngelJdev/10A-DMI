# Práctica 05: Cards y botones

Aplicación Flutter independiente para explorar widgets de Material 3. Incluye una pantalla principal para navegar entre ejemplos de botones, tarjetas e indicadores de progreso.

## Ejecutar

Desde esta carpeta:

```powershell
flutter run
```

El workspace de VS Code abre las terminales nuevas directamente en `docs/practica05`. También puedes iniciar la app desde **Run and Debug** con `practica05 (Cards y botones)`.

## Contenido

- **Botones:** Elevated, Filled, Outlined, Text, botones con icono, estado deshabilitado y botones de icono.
- **Tarjetas:** elevaciones 0 a 5, tarjetas con borde y cuatro ejemplos con imágenes.
- **Progress Indicators:** indicadores circulares indeterminados y un ejemplo combinado circular y lineal.
- **Diseño:** tema Material 3 con paleta guinda.
